# Ticketing System

## Project Overview
A web-based ticketing system that allows customers to browse events, purchase tickets, and receive electronic tickets.

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL

## Project Structure
- `frontend/`: User interface
- `backend/`: Flask API and business logic
- `database/`: SQL schema and sample data
- `tests/`: Test cases and testing results
- `docs/`: Project documentation

## Team Workflow
Each member is responsible for their assigned module. Code must be tested before being merged into the main branch.
